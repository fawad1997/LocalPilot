Quantara (trading bot)

Lets the agent read your local Quantara dashboard (status, trades, why it isn't trading, sessions, research). It never places trades or changes settings.

With a token, the agent also gets quantara_halt (emergency stop: no new entries). You confirm it every time; it is never run by schedules or MCP clients, and resuming stays on Quantara's dashboard.

Site notes

Short notes the agent saved about websites (site_note). It sees a site's notes whenever it works on that site. Removing one takes effect immediately.

    Sites that block debugging

    These sites reloaded or blanked themselves while LocalPilot read their console, so LocalPilot no longer reads the console there (everything else still works). Forget a site to try again.
