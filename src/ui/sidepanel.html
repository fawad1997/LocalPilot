The PC bridge lets LocalPilot save files (CSV, notes) into your folders, run the job-board and application flows, and upload files from those folders. Attaching a file with the paperclip works without it.

  1. Install Node.js 18 or newer, if you do not have it.
  2. Open a terminal in the LocalPilot folder (the folder you picked in chrome://extensions → Load unpacked).
  3. Run this command once:
    node host/install.mjs
  4. Reload LocalPilot: and press the reload arrow on LocalPilot.

Folders it may use are set in host/config.json. To remove it later: node host/install.mjs --uninstall.

Commands
    Attach files

    Press the paperclip next to the box (or drop files on the panel) and send your message with them. LocalPilot can then:

    • read text files (txt, csv, json, md…) and see images,
    • upload a file into a page's file field: "Upload the attached CV to the resume field."

    Up to 15 MB per file. Attached files stay available until you start a new chat.

    Things to try

    Click one to put it in the box, then edit it.

    Permission modes
    • Ask once per site: asks the first time it acts on each website.
    • Ask every action: asks before every click, typing or upload.
    • Plan, then act: writes a plan first; you approve, edit or cancel it.
    • Act without asking: never asks. Use only on sites you trust.

    Reading pages never needs approval. LocalPilot never solves CAPTCHAs and never types passwords or card numbers.
