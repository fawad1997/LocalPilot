A browser agent that runs on your model.

LocalPilot lives in Chrome's side panel. It opens pages, reads them, clicks, types, fills forms and takes screenshots while you watch, powered by Ollama, LM Studio, llama.cpp, vLLM or any OpenAI/Anthropic-compatible server.

  • Your real Chrome: your logins, cookies and tabs
  • Pages and prompts go only to the model you run
  • No account, no subscription, no telemetry

What it can do

The same browser tools a cloud agent has, plus a few things that only make sense on your own PC.

🖱️

Browse and act

Reads pages as a compact accessibility tree, clicks by ref or numbered screenshot mark, types, scrolls, handles tabs and dialogs.

📝

Fill forms

React/Vue inputs, selects, checkboxes and web components. Saved values are never shown to the model; password fields are refused.

📊

Collect and export

Extract repeating lists, read a site's own JSON responses, and write CSV, JSON or Markdown into allowlisted PC folders.

🧪

Test a website

/test crawls read-only for JS errors, broken links, unlabeled fields, phone layouts and slow pages, then writes a report.

🎬

Record

/record … saves a captioned GIF of the task, with a red circle on every click.

⏰

Schedule

Run saved tasks daily, weekly or every N minutes, or watch a page and get notified when it changes.

💼

Job search

Recipes for LinkedIn, BOSS直聘, 猎聘, 51job and 智联: collected, de-duplicated and saved as CSV.

🤖

🛡️

CAPTCHA checks

Turnstile, “verify you are human”, checkbox, slider and press-and-hold checks, solved locally when you turn it on.

Claude Code · MCP

Let Claude Code drive your real browser.

LocalPilot ships an MCP server. Claude Code gets the same browser tools (navigate, click, read, forms, captures, recipes), and every session works in one shared, unfocused “LocalPilot MCP” window, so it never takes over the tabs you're using.

Claude Code⇄mcp-server.mjs⇄native host⇄extension⇄Chrome
npm run host:install claude mcp add localpilot -s local -- node "<project folder>/host/mcp-server.mjs"

Then just ask: “Use localpilot to test http://localhost:3000 for bugs.”

Install

Running in three steps.

No store listing, no sign-up. Load the folder, point it at a model, and ask.

Load the extension

  1. Download or clone the repo.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the folder.
  4. Press Alt+Shift+L to open the panel.
git clone https://github.com/fawad1997/LocalPilot

Connect a model

  1. Pull a vision model with Ollama.
  2. Allow the extension to call it (Windows, once).
  3. In the panel: gear → Preset “Ollama” → Test → Save.
ollama pull qwen2.5vl:7b setx OLLAMA_ORIGINS "chrome-extension://*"

Give it a task

  1. Open any site and the side panel.
  2. Type what you want done.
  3. Approve the site once, or always.
